#  PIF — Programação e Introdução à Computação

Repositório destinado às atividades, listas de exercícios e práticas desenvolvidas na disciplina de **Programação e Introdução à Computação (PIF)** durante o curso de **Análise e Desenvolvimento de Sistemas (ADS)** na CESAR School.
O objetivo deste repositório é organizar as atividades realizadas ao longo da disciplina e registrar minha evolução no aprendizado de programação e lógica computacional.
